# Prishka Annam — Premium Bihar Makhana

Modern, high-converting, responsive landing page and product catalog website for **Prishka Annam**, a premium Indian healthy snacking brand specializing in hand-picked Bihar Makhana (Fox Nuts / Lotus Seeds).

## Brand Positioning
- **Core Message**: *Daily Snacking, Healthy Living — Fuel Your Day with Guilt-Free Crunch.*
- **Attributes**: 100% Natural • Pesticide Free • Rich in Protein & Fibre.
- **Palette**: Warm Terracotta Rust (`#AA3B10`), Embossed Metallic Gold (`#D4A446`), Deep Forest Jade (`#1E4E2B`), on warm Makhana Ivory (`#FFF9F2`).

## Key Features
1. **Interactive Hero Banner**:
   - Realistic stand-up pouch mockup with official brand emblem.
   - Real-time physics-based pouring animation where 3D photographic makhana puffs cascade from the tilted packet into a ghee-roasted brass bowl on hover or tap.
   - Natural culinary kitchen stage with burlap harvest sacks and traditional spices.
2. **Everyday Snacking Use Cases**:
   - Pan-roasting for evening tea, healthy home cooking, kids' tiffins, and active fitness routines.
3. **Lifestyle Photography Gallery**:
   - High-resolution editorial photography showcasing farm harvest purity, tea pairing, and daily pantry snacking.
4. **Interactive Dual-Mode Product Catalog**:
   - Grades: **4+ Handpick** (Classic Daily Size), **5+ Handpick** (Large Crunch), and **6+ Handpick** (Super Jumbo).
   - Pack Sizes: 75g (Trial Pack), 100g (Standard), 250g (Family Pack), and 500g (Super Saver).
   - Real-time toggle between **Printed MRP** and **Special Offer Price**.
   - Dual viewing mode: Authentic Flyer Pricing Board vs Responsive Product Cards.
5. **Bulk & Apartment Society Inquiries**:
   - Dedicated inquiry form for societies, apartments, and retail dealers.
6. **Upcoming Natural Flavours Teaser**:
   - Clean callout banner for upcoming flavoured makhana varieties.

## Getting Started
Simply open `index.html` in any modern web browser or serve via any static web server (GitHub Pages, Netlify, Vercel, etc.).

```bash
# Example with python static server
python3 -m http.server 8000
```
